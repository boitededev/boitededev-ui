Boite de Dev UI

Un fichier CSS sans dépendance (css/style.css) et quelques controllers Stimulus (js/). Il contient les tokens de la charte, les composants et quelques classes utilitaires. Aucun outil de build.

Installation : CSS seul

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/boitededev/boitededev-ui@v1.1.0/css/style.css">

Installation : avec les controllers JS

Le projet fournit Stimulus, le kit ne l'embarque pas. Les controllers propres au projet s'enregistrent à côté, comme d'habitude. 

<script type="importmap">
{
  "imports": {
    "@hotwired/stimulus": "https://cdn.jsdelivr.net/npm/@hotwired/stimulus@3.2.1/dist/stimulus.js",
    "boitededev-ui": "https://cdn.jsdelivr.net/gh/boitededev/boitededev-ui@v1.1.0/js/index.js"
  }
}
</script>
<script type="module">
  import { Application } from "@hotwired/stimulus"
  import { registerControllers } from "boitededev-ui"

  const app = Application.start()
  registerControllers(app)
</script>

Icônes

Un jeu d'icônes au trait, sans dépendance : chaque icône est un SVG intégré au CSS et appliqué en masque. Elle prend donc la couleur du texte (currentColor) et sa taille suit la police. Ajoutez aria-hidden="true" : l'icône est décorative, le texte porte le sens.

Le jeu complet

Cliquez sur une icône pour copier son code.

Tailles & couleurs

1.25em par défaut, puis .icon-sm (1em), .icon-lg (1.5em), .icon-xl (2em). Pour une taille précise : style="--icon-size: 20px".

Marges et paddings

m = margin, p = padding. Le suffixe indique le côté : rien pour les 4 côtés, x pour gauche et droite, y pour haut et bas, puis t, b, l, r pour un seul côté. Le chiffre renvoie à l'échelle d'espacements.

Accessibilité

  • :focus-visible affiche un anneau bleu, seulement à la navigation au clavier (testez avec Tab).
  • .sr-only cache un texte à l'écran tout en le laissant aux lecteurs d'écran.
  • .skip est le lien « Aller au contenu ». Il n'apparaît qu'au focus : appuyez sur Tab en haut de cette page.
  • Les ancres [id] ne passent pas sous la navbar sticky.

.reveal : apparition au scroll

Nécessite la classe js sur <html> et ce petit script : 

<script>
  document.documentElement.classList.add("js");
  const io = new IntersectionObserver((entries) => {
    entries.forEach((e) => {
      if (e.isIntersecting) {
        e.target.classList.add("in");
        io.unobserve(e.target);
      }
    });
  }, { threshold: 0.15 });
  document.querySelectorAll(".reveal").forEach((el) => io.observe(el));
</script>
