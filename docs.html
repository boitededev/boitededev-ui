Boite de Dev UI

Un fichier CSS sans dépendance (css/style.css) et quelques controllers Stimulus (js/). Il contient les tokens de la charte, les composants et quelques classes utilitaires, sans outil de build.

Installation : CSS seul

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/boitededev/boitededev-ui@v1.3.0/css/style.css">

Installation : avec les controllers JS

Le projet fournit Stimulus, le kit ne l'embarque pas. Les controllers propres au projet s'enregistrent à côté, comme d'habitude. 

<script type="importmap">
{
  "imports": {
    "@hotwired/stimulus": "https://cdn.jsdelivr.net/npm/@hotwired/stimulus@3.2.1/dist/stimulus.js",
    "boitededev-ui": "https://cdn.jsdelivr.net/gh/boitededev/boitededev-ui@v1.3.0/js/index.js"
  }
}
</script>
<script type="module">
  import { Application } from "@hotwired/stimulus"
  import { registerControllers } from "boitededev-ui"

  const app = Application.start()
  registerControllers(app)
</script>

Lien actif automatique

Le controller Stimulus nav (js/controllers/nav_controller.js) pose aria-current="page" sur le lien dont l'adresse correspond à la page ouverte. Il cherche les liens dans data-nav-target="links" s'il existe, sinon dans l'élément du controller. /factures et /factures/ comptent comme la même page.

Par défaut, l'adresse doit correspondre exactement. Avec data-nav-match="prefix", le lien reste aussi actif sur ses sous-pages : ici, « Prospects » est marqué sur /prospects/12, mais pas sur /prospectsX. Un seul lien est actif à la fois. Une correspondance exacte l'emporte, sinon c'est le préfixe le plus long. Mettre / en préfixe n'a aucun effet, sinon « Accueil » serait actif partout.

Le lien actif est recalculé à chaque navigation Turbo et au retour arrière du navigateur, ce qui fonctionne aussi avec une navbar en data-turbo-permanent. Sur mobile, quand les liens défilent, le lien actif est centré dans la barre. 

<nav class="navbar-links" data-controller="nav">
  <a href="/">Accueil</a>
  <a href="/prospects" data-nav-match="prefix">Prospects</a>
  <a href="/factures" data-nav-match="prefix">Factures</a>
</nav>

Sommaire qui suit la lecture

Pour une page découpée en sections, le controller scrollspy (js/controllers/scrollspy_controller.js) marque le lien d'ancre de la section en cours de lecture avec aria-current="location". Le sommaire de gauche et la navbar de cette page l'utilisent : faites défiler pour voir le lien changer.

Une section devient active quand son haut passe sous la navbar, à l'endroit où un clic sur le lien l'amène. Pour placer cette ligne ailleurs, indiquez une distance en pixels depuis le haut de la fenêtre avec data-scrollspy-offset-value. En bas de page, la dernière section est active, même si elle est trop courte pour atteindre la ligne. 

<nav class="navbar-links" data-controller="scrollspy">
  <a href="#intro">Introduction</a>
  <a href="#tarifs">Tarifs</a>
  <a href="#contact">Contact</a>
</nav>

Conteneur

Le conteneur .toasts se place une seule fois dans le layout, en bas à droite de l'écran (sur toute la largeur sur mobile). Il doit être présent dès le chargement, même vide : les lecteurs d'écran n'annoncent que ce qui est ajouté dans une zone aria-live déjà en place. Les messages flash du serveur peuvent être rendus directement dedans. 

<div id="toasts" class="toasts" aria-live="polite"></div>

Avec Turbo Streams

Le serveur ajoute un toast dans #toasts, et le controller se lance dès qu'il apparaît. Avec Turbo, les toasts sont retirés avant la mise en cache de la page, donc ils ne réapparaissent pas au retour arrière. 

<turbo-stream action="append" target="toasts">
  <template>
    <div class="toast toast-success" data-controller="toast">
      …
    </div>
  </template>
</turbo-stream>

Menu déroulant

Basé sur l'attribut natif popover : le navigateur ferme le menu au clic à l'extérieur ou avec Échap, et rend le focus au bouton. Le menu s'affiche au-dessus de tout, même dans un .table-wrap qui coupe ce qui dépasse. Le controller Stimulus dropdown (js/controllers/dropdown_controller.js) relie le bouton au menu sans id, le place sous le bouton et gère les flèches du clavier.

Éléments

Un .menu-item peut être un <a> ou un <button>, y compris dans un formulaire (comme celui de button_to). Un clic sur un élément ferme le menu. .menu-item-danger colore une action destructrice, <hr class="menu-sep"> sépare deux groupes, et un élément disabled est grisé et sauté par les flèches.

Position

Le menu s'aligne sur le bord droit du bouton, ce qui convient à un bouton en bout de ligne. Avec data-dropdown-align-value="start" sur l'élément du controller, il s'aligne à gauche. Il s'ouvre vers le haut quand il manque de place en bas, reste dans la fenêtre et suit le bouton si la page défile.

Onglets

Le controller Stimulus tabs (js/controllers/tabs_controller.js) relie le n-ième onglet au n-ième panneau et pose les attributs ARIA. Au clavier, les flèches gauche et droite changent d'onglet, Début et Fin vont au premier et au dernier, et Tab passe au contenu du panneau.

Onglet ouvert

Mettez hidden sur les panneaux qui ne sont pas ouverts au départ : sinon, tous s'affichent le temps que le JS se charge. Pour ouvrir un autre onglet que le premier, ajoutez aria-selected="true" sur cet onglet.

Si un panneau a un id, l'onglet peut aussi s'ouvrir depuis l'URL : avec id="factures", l'adresse /clients/4#factures ouvre l'onglet Factures. Changer d'onglet met l'ancre à jour, donc un rechargement ou une redirection vers cette adresse retombe sur le même onglet. 

<div class="tab-panel" role="tabpanel" data-tabs-target="panel" id="factures" hidden>

Chargement à l'ouverture

Une <turbo-frame loading="lazy"> dans un panneau ne se charge qu'à l'ouverture de l'onglet, sans code en plus. Pour autre chose, le controller envoie l'événement tabs:change avec l'onglet, le panneau et son index. 

<div class="tab-panel" role="tabpanel" data-tabs-target="panel" hidden>
  <turbo-frame id="factures" src="/clients/4/factures" loading="lazy">
    <progress class="progress" aria-label="Chargement"></progress>
  </turbo-frame>
</div>

Onglets qui changent de page

Quand chaque onglet est une page à part, utilisez des liens <a class="tab"> avec le controller nav à la place de tabs. Le lien de la page courante prend aria-current="page" et le même style qu'un onglet ouvert. 

<nav class="tabs" data-controller="nav" aria-label="Fiche client">
  <a class="tab" href="/clients/4">Infos</a>
  <a class="tab" href="/clients/4/factures" data-nav-match="prefix">Factures</a>
</nav>

Marges et paddings

.reveal : apparition au scroll

Nécessite la classe js sur <html> et ce petit script : 

<script>
  document.documentElement.classList.add("js");
  const io = new IntersectionObserver((entries) => {
    entries.forEach((e) => {
      if (e.isIntersecting) {
        e.target.classList.add("in");
        io.unobserve(e.target);
      }
    });
  }, { threshold: 0.15 });
  document.querySelectorAll(".reveal").forEach((el) => io.observe(el));
</script>
